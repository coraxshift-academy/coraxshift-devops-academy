## 🎯 What you will be able to do

| | |
|---|---|
| 🧱 **Describe** | Write a Terraform configuration with providers, resources, variables and outputs |
| 🔍 **Preview** | Read a plan and tell create, update and replace apart |
| 🏗️ **Build** | Apply a saved plan and prove the result |
| 🔁 **Repeat** | Show that running Terraform twice changes nothing |
| 🧭 **Drift** | Spot and repair changes made behind Terraform's back |
| 🔐 **Protect** | Keep state, plans and secrets out of Git |
| 🧹 **Clean up** | Preview and destroy a lab, and prove it is gone |
| 💼 **Show off** | Put the full journey in your portfolio |

> [!NOTE]
> No cost and no powerful laptop. You practise in a free Codespace in your browser. You do **not** need to be a programmer, and nothing here touches the cloud. Take **Linux**, **Bash** and **Git and GitHub for Beginners** first.

## ⏱️ How long it takes

3 classes (2 hours each) + an assignment (2 to 3 hours) + a role play, a quiz and a recap = **about 10 hours in total**. Go at your own pace.

## 🛡️ Safety rules

- Read a command before you run it, especially if it deletes or overwrites anything.
- Only run what the lessons tell you to run, and only on your own practice Codespace.
- Never put passwords, tokens or keys inside a file, a commit or a screenshot.
- Keep forwarded ports **Private**.
- Save your own work in **your own repositories**, not in this course repository.
