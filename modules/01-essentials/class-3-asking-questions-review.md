

# **Class 3: Asking Questions, Review, Role Play**

Time: 2 hours

## **Definitions for this class**

Stakeholder: A person who cares about the project but may not know tech. Example: A shop owner.
Jargon: Tech words that a non-tech person does not know. Example: Saying IP address without explaining it.
Template: A fixed structure you fill in every time.

## **Part 1: Guidelines for asking questions effectively**

Use this template every time:
1. What I was trying to do:
2. What I did:
3. What I expected:
4. What I saw instead, copy the exact error:
5. What I already tried:

Bad question: My code is not working.
Good question: I was trying to open my VS Code terminal and run dir. I clicked Terminal, then New Terminal. I expected to see my files. I saw the terminal did not open. I already tried closing and reopening VS Code.

If you ask like this, you get help fast.

## **Part 2: Review for Week 1**

Answer in your own words, out loud, with a partner:
1. What is DNS, in one sentence, without jargon?
2. What is the difference between ping to an IP and ping to a name?
3. What is the difference between two-tier and three-tier?
4. Which DNS record connects a domain to an IPv4 address?
5. What is the first step when something breaks?
