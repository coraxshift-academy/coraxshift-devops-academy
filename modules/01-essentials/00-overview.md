# Week 1: Essentials - Internet, Networking and Tools Basics
Time: 3 classes, 2 hours each. Quiz at end of Week 1.

## Welcome to CoraxShift
We build, we break, we fix, we ship. One project from Week 1 to Week 12.
Your portfolio starts in Week 1. Every week you push to your own public portfolio repo.

## How to get most of CoraxShift
1. Come to all 3 classes per week
2. Do the lab, do not just watch
3. Push every week to your portfolio
4. Take the weekly quiz. 90 percent earns the badge.
5. If it breaks, write what broke. That is learning.

## Week 1 map
Class 1: Welcome + Internet + Domain and DNS
Class 2: App Architecture + VS Code + AI + Troubleshooting
Class 3: Asking Questions + Review + Role Play + Assignment
Then: Quiz Week 1 + Assignment 1

## What you will build this week
1. Your internet diagram
2. Your VS Code setup, verified
3. Your CoraxReads explanation
4. Your first portfolio push

## Pass check for Week 1
- You can open terminal on Windows, Mac, or Linux
- You can run ping and nslookup and read the output
- You can explain DNS in plain words
- You can open VS Code, open terminal inside it, and run whoami
- Your assignment folder is on GitHub
