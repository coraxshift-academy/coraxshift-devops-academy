# Class 3: Demo and Reflect

**Time:** 2 hours
**Audience:** a technical peer and a non-technical stakeholder.

## Five-minute demo

1. **Problem:** Who needs the bookstore and why?
2. **Architecture:** Explain the request path using your diagram.
3. **Change:** Show a small reviewed feature and passing CI.
4. **Operations:** Show a health check and one useful dashboard/alert.
5. **Recovery:** Explain the rollback and demonstrate it in the lab if safe.
6. **Learning:** Name a failure, how you diagnosed it, and what you changed.

Avoid saying "it is secure" or "it scales" without evidence. State limitations and what you would improve next.

## Peer review

Ask your reviewer to check whether they can:

- Start the system using only the README.
- Identify where secrets belong and where they must not go.
- Find the latest passing build and deployment evidence.
- Follow the first steps in your runbook.

## Finish

Confirm cloud resources are cleaned up, secrets are absent from Git, and the portfolio links work. Add the earned badge only after the weekly assessment passes.
