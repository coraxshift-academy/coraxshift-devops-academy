# Assignment 5: Plan a CoraxReads Feature

**Time:** 2-3 hours
**Submit in:** your portfolio repo, `modules/05-sdlc/assignment-5/`.

## Task 1 - Write the issue

Choose one feature: book catalog, search, or health endpoint. Write the user story, at least three measurable acceptance criteria, explicit out-of-scope behavior, risks, and a reviewer.

## Task 2 - Plan the work

Break the feature into small tasks. For each task, name the file or component, expected change, and check that proves completion. Draw the request flow with arrows and label the browser, app, and data store.

## Task 3 - Create test cases

For each acceptance criterion, record starting state, action, and expected result. Include a normal case, an empty/missing case, and a dependency failure case. State whether each is unit, integration, or end-to-end.

## Task 4 - Prepare release and rollback notes

Write a release checklist, a short release note, and rollback steps. Explain why the previous version might not work after an irreversible database change.

## Task 5 - Review

Ask a partner to try to find ambiguity in the criteria. Revise the issue based on feedback.

## Submit

Issue link or Markdown issue, request-flow diagram, test plan, release note, rollback plan, and a short reflection on one risk you discovered.
