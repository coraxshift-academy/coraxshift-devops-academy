**# CoraxShift DevOps Academy

Learn DevOps by building, not by watching.

No long theory. No confusing words. You build a real project every week.

## Who is this for?
Beginners who want to learn Docker, Kubernetes, Cloud and CI/CD and have a portfolio to show for it.

## How it works
Each week you do 3 things:
1. Learn - One simple lesson in plain language
2. Build - One hands-on lab
3. Push - Push your work to 【entity-GitHub¦canonical_name=GitHub】

If you do the work, you finish with a portfolio.

## What you need
A laptop, a 【entity-GitHub¦canonical_name=GitHub】 account, and 5 to 7 hours per week.

## The 4 Weeks
Week 1: Linux + Git + Docker - Run your first container
Week 2: Cloud + Terraform - Put your app in the cloud
Week 3: Kubernetes + CI/CD - Deploy it automatically
Week 4: Monitoring + Capstone - Make it professional

## Rules
1. Do the lab, do not just read it
2. Document what you did in your README
3. If it breaks, fix it. That is the real DevOps skill.
