# Quiz: Git and GitHub for Beginners

**Coraxshift DevOps Academy · Learn. Build. Deploy. Grow.**

🏅 **12 questions, about 20 minutes.** 8 are *Choose ONE*, 4 are *Choose ALL that apply*.
Score **90% (11 out of 12) or more** to earn your **Git and GitHub for Beginners badge**. Below that, you get one retake after reviewing Class 1 and Class 2.

Every question comes from something you practised in this course. Answer all of them **before** you look at the answers.

## Questions

**Q1. Choose ONE.** Which command moves a changed file into the staging area?
- A. `git commit`
- B. `git add`
- C. `git push`
- D. `git status`

**Q2. Choose ONE.** You want to see what will go into your next commit. Which command shows it?
- A. `git diff`
- B. `git log`
- C. `git diff --staged`
- D. `git branch`

**Q3. Choose ONE.** What does `HEAD` mean?
- A. The first commit ever made
- B. The remote repository
- C. The largest file in the project
- D. Where you are now in the history

**Q4. Choose ONE.** Which is the best commit message?
- A. `update`
- B. `Fix wrong oven temperature in bread recipe`
- C. `changes`
- D. `asdf`

**Q5. Choose ONE.** You committed a file with a password in it last week, and now you add it to `.gitignore`. What happens?
- A. The password is removed from history
- B. The file is deleted from GitHub
- C. Nothing: `.gitignore` only affects files Git is not already tracking, and the history still holds the password
- D. Git refuses all future commits

**Q6. Choose ONE.** Which command creates a branch and moves you onto it?
- A. `git branch -d idea`
- B. `git switch -c idea`
- C. `git merge idea`
- D. `git clone idea`

**Q7. Choose ONE.** You committed a mistake that is already on GitHub, and teammates have pulled it. What is the safest undo?
- A. `git reset --hard` and `git push --force`
- B. Delete the repository
- C. `git restore .`
- D. `git revert` on that commit

**Q8. Choose ONE.** What is a pull request?
- A. A request to download a repository
- B. A proposal to merge your branch, which others can review first
- C. A command that deletes a branch
- D. A way to rename `main`

**Q9. Choose ALL that apply.** Which of these show something about your changes without changing anything?
- A. `git status`
- B. `git diff`
- C. `git log --oneline`
- D. `git restore file`

**Q10. Choose ALL that apply.** What is true about a merge conflict?
- A. Git marks the clashing lines with `<<<<<<<`, `=======` and `>>>>>>>`
- B. You fix it by editing the file, then running `git add` and `git commit`
- C. It means your repository is broken beyond repair
- D. `git merge --abort` can cancel the merge

**Q11. Choose ALL that apply.** Which belong in a `.gitignore` file?
- A. `.env`
- B. `*.log`
- C. `README.md`
- D. `*.tmp`

**Q12. Choose ALL that apply.** Which are unsafe habits?
- A. Pushing a `.env` file with keys
- B. Using `git push --force` on a shared branch
- C. Opening a pull request for review before merging
- D. Running `git status` before and after each command
