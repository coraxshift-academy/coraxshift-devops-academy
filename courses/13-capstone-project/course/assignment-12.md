# Assignment 12: Present the CoraxReads Capstone

**Time:** 4-6 hours
**Submit in:** your portfolio repository.

## Task 1 - Finish the architecture and README

Update the architecture diagram to match the real implementation. Write the README using the Class 1 order. Test each command from a fresh checkout or have a peer follow it.

## Task 2 - Show the delivery path

Link a reviewed pull request, passing CI run, image identifier, and deployment evidence. Explain where approval happens and what identity is used. Redact sensitive details.

## Task 3 - Show operations

Provide a dashboard with at least three useful signals, one actionable alert, and a runbook. Show a sanitized successful health check.

## Task 4 - Rehearse recovery

In a disposable environment, trigger one safe failure. Capture the timeline, evidence, recovery action, and verification. Restore the environment and prove it is healthy again.

## Task 5 - Close the account footprint

Check and clean up all lab compute, disks, snapshots, IP allocations, load balancers, clusters, containers, and other billable resources. Never delete shared or production resources. Record final checks without exposing account identifiers.

## Task 6 - Present and reflect

Give a five-minute demo. Include one thing that broke, one design tradeoff, and one next improvement. Ask for peer review and update your README.

## Evaluation rubric (100 points)

- Working system and reproducible setup: 20
- Architecture and documentation: 15
- Tests and CI: 15
- Secure identity, secrets, and network choices: 15
- Monitoring, alert, and runbook: 15
- Recovery and cost cleanup: 10
- Clear demo and honest reflection: 10

Pass the course badge only after required sections are complete and reviewed.
