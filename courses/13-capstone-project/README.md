## What this course is

This is where the twelve courses before it become one story. You take CoraxReads, the app you have been shipping in pieces, and show it running like a real service: built by a pipeline, deployed by Git, watched by dashboards, and recoverable when something breaks.

You are not learning a new tool here. You are learning to **explain and defend** what you built, which is exactly what an interview and a first job will ask you to do.

## What you produce

- An architecture diagram and a README someone else can follow.
- Application and database run instructions that work on a clean machine.
- The infrastructure and configuration artifacts you used.
- CI run and deployment evidence.
- A monitoring dashboard, one alert, and a runbook.
- A security and cost checklist.
- A short demo and a written reflection.

Start with the [overview](00-overview.md), then follow the classes in order.

## How you are assessed

Nothing here is marked by a quiz. You pass this course when you can show a working service and answer questions about it without notes: why this design, what breaks first, how you would know, and how you would recover.

See [Assignment 12](assignment-12.md) for the submission checklist and [Troubleshooting](troubleshooting.md) if a step fails.

## Cost

The capstone can be completed with $0 of cloud spend using Codespaces and a local Kubernetes cluster. If you choose to run it on a real cloud account, read the cost box in Class 1 first and clean up at the end of every session.
