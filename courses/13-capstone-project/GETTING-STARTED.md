# 🚀 Getting Started

**CoraxReads Capstone** · Coraxshift DevOps Academy

</div>

By the time you reach this course you have already built most of CoraxReads. This page only makes sure your workspace is ready for the final three classes.

## ✅ What you need

- A GitHub account with access to this repository.
- The CoraxReads repository you have been building in during the earlier courses.
- A GitHub Codespace, or your own machine with Docker installed.
- Your notes and evidence from the previous courses: pipeline runs, deployment screenshots, dashboards.

## 🖥️ Step 1: Open your workspace

1. Open your CoraxReads project repository, not this one.
2. Click **Code**, then **Codespaces**, then **Create codespace on main**, or reopen an existing codespace from github.com/codespaces.
3. In the terminal, run `pwd`. You should be inside your project folder.

## 🔍 Step 2: Check your evidence is complete

Before Class 1, confirm you can still find:

1. One successful CI run for your latest change.
2. One deployment you triggered, with the change visible in the running app.
3. One dashboard or log view showing the app healthy.
4. The commands you use to start and stop everything.

If any of those are missing, rebuild them now. Class 1 assumes they exist.

## ▶️ Step 3: Start Class 1

Open [Class 1: Assemble the evidence](course/class-1.md). Bring a pen: you will draw the system before you write about it.
