## 🎯 What you will be able to do

| | |
|---|---|
| ✍️ **Write** | Your own Bash scripts: small saved recipes the computer follows exactly |
| 🔤 **Use** | Variables, arguments and user input, with quotes in the right places |
| 🔀 **Decide** | Make a script choose with `if`, `else` and `case` |
| 🔁 **Repeat** | Do a job for many files or lines with `for` and `while` loops |
| 🧱 **Organise** | Break a script into functions you can reuse |
| 🛡️ **Stay safe** | Make scripts stop on errors, refuse to overwrite things, and never delete by accident |
| 🩺 **Check health** | A script that tells you clearly if a website is healthy or not |
| 💾 **Back up** | A dated backup script, and a restore test that *proves* the backup works |
| 📊 **Read logs** | A script that turns a messy server log into a short report |
| 🐞 **Debug** | Find why a script fails using `bash -n` and `bash -x` |

> [!NOTE]
> No cloud account, no cost and no powerful laptop. You practise in a free Codespace in your browser. You do **not** need Linux experience, but if you can already open a terminal and type a command, you will move faster.

## ⏱️ How long it takes

3 classes (2 hours each) + an assignment (2 to 3 hours) + a role play, a quiz and a recap = **about 10 hours in total**. Go at your own pace.

## 🛡️ Safety rules

- Read a script before you run it, especially if it uses `sudo`, changes files or deletes anything.
- Only run what the lessons tell you to run, and only on your own practice Codespace.
- Never put passwords, tokens or keys inside a script or a screenshot.
- Keep forwarded ports **Private**.
- Save your own work in **your portfolio repository**, not in this course repository.
