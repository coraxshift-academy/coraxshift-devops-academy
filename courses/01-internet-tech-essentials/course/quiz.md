# Quiz: Internet & Tech Essentials

**Coraxshift DevOps Academy · Learn. Build. Deploy. Grow.**

🏅 **12 questions, about 20 minutes.** 8 are *Choose ONE*, 4 are *Choose ALL that apply*.
Score **90% (11 out of 12) or more** to earn your **Internet & Tech Essentials badge**. Below that, you get one retake after reviewing Class 1 and Class 2.

Every question comes from something you practised in this course. Answer all of them **before** you look at the answers. Each explanation says why the right answer is right *and* why the others are wrong, and that is where most of the learning happens.

## Questions

**Q1. Choose ONE.** You run ping 8.8.8.8 and get replies. You run ping google.com and get could not resolve host. What is most likely broken?
- A. Internet cable
- B. DNS
- C. VS Code
- D. Your browser cache

**Q2. Choose ONE.** You run nslookup google.com and see Server 192.168.1.1, Name google.com, Addresses 142.250.80.46. What did nslookup do?
- A. It turned the name into an IP by asking DNS
- B. It installed Google
- C. It checked your VS Code theme
- D. It changed your IP address

**Q3. Choose ONE.** CoraxReads domain is coraxreads.com and server IP is 102.130.45.78. Which DNS record connects them?
- A. A record
- B. CNAME record
- C. MX record
- D. TXT record

**Q4. Choose ONE.** In a three-tier app, where does the business logic live?
- A. Frontend
- B. Backend
- C. Database
- D. Browser cache

**Q5. Choose ONE.** A user sees Not Secure in the browser when opening a site. What is most likely missing?
- A. HTTPS
- B. DNS
- C. VS Code
- D. A domain

**Q6. Choose ONE.** In VS Code terminal on Windows, which command lists files in the current folder?
- A. dir
- B. ls
- C. pwd
- D. whoami

**Q7. Choose ONE.** Which ChatGPT prompt is best for learning?
- A. My code is not working. Fix it.
- B. I ran ping google.com and got could not resolve host, but ping 8.8.8.8 works. What is most likely broken and how do I check it? Explain to a beginner.
- C. Tell me everything about networking.
- D. Give me the answer.

**Q8. Choose ONE.** You change one line and get an error. What is the first step?
- A. Read the full error message
- B. Delete the whole project
- C. Ask AI with no context
- D. Reinstall VS Code

**Q9. Choose ALL that apply.** Which are true about packet switching?
- A. Packets can take different routes to the destination
- B. Packets are reassembled at the destination
- C. All packets always take the same route
- D. If one packet is lost, the whole internet fails

**Q10. Choose ALL that apply.** Which are true about TCP/IP?
- A. TCP divides application data into segments
- B. IP addresses each packet
- C. TCP provides ordered delivery to the application
- D. HTTP is the same thing as TCP

**Q11. Choose ALL that apply.** Which are good questions?
- A. I was trying to run dir in VS Code terminal. I clicked Terminal, then New Terminal. I expected to see my files. I saw no terminal. I tried reopening VS Code.
- B. My code is not working.
- C. I was trying to ping google.com. I ran ping 8.8.8.8 and it worked. I expected ping google.com to work. I saw could not resolve host. I tried checking WiFi.
- D. Fix this.

**Q12. Choose ALL that apply.** Which are true about three-tier architecture?
- A. Frontend shows the UI
- B. Backend does the work
- C. Database stores the data
- D. Frontend talks directly to Database in three-tier
