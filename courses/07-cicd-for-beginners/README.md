## 🎯 What you will be able to do

| | |
|---|---|
| 🚦 **Trigger** | Make a workflow run on every push |
| ✅ **Check** | Run style checks and tests automatically, on two Python versions |
| 🔒 **Protect** | Lock `main` so only checked code can enter |
| 📦 **Build** | Build and smoke test a Docker image, then publish it |
| 🔑 **Secure** | Keep a secret safe and require approval before production |
| 🔙 **Roll back** | Stop a bad release and undo it with a revert |
| 💼 **Show off** | Put the full journey in your portfolio |

> [!NOTE]
> No cost and no powerful laptop. You practise in a free Codespace in your browser. You do **not** need to be a programmer, and Docker is already in your Codespace, and Class 1 checks your GitHub sign-in. Take **Linux**, **Bash** and **Git and GitHub for Beginners** first.

## ⏱️ How long it takes

3 classes (2 hours each) + an assignment (2 to 3 hours) + a role play, a quiz and a recap = **about 10 hours in total**. Go at your own pace.

## 🛡️ Safety rules

- Read a command before you run it, especially if it deletes or overwrites anything.
- Only run what the lessons tell you to run, and only on your own practice Codespace.
- Never put passwords, tokens or keys inside a file, a commit or a screenshot.
- Keep forwarded ports **Private**.
- Save your own work in **your own repositories**, not in this course repository.
