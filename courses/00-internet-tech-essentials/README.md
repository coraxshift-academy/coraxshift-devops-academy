## 🎯 What you will be able to do

| | |
|---|---|
| 🌍 **Explain** | What really happens between typing `google.com` and seeing the page |
| 🔎 **Test** | Check a connection with `ping` and look up a name with `nslookup`, and read the answers |
| 📖 **Understand** | What an IP address, DNS, a domain, a server, a port and HTTPS are, in plain words |
| 🏗️ **Compare** | Two-tier and three-tier apps, and say which is better and why |
| 🧰 **Set up** | VS Code and its built-in terminal, and prove it is yours |
| 🤖 **Use AI well** | Ask an AI assistant good questions and check its answers instead of trusting them |
| 🛠️ **Fix** | Troubleshoot with a 5-step method and ask for help so people actually help you |
| 🗣️ **Teach** | Explain all of it to someone who has never heard these words |

> [!NOTE]
> No cloud account, no cost and no powerful laptop. If your computer can open a web browser, it can do this course.

## ⏱️ How long it takes

3 classes (2 hours each) + an assignment (2 to 3 hours) + a role play and a quiz = **about 8 hours in total**. Go at your own pace.

## 🛡️ Safety rules

- Never paste passwords, tokens or keys into screenshots, AI tools, or anything public.
- Only run the commands in the lessons. If you are unsure what a command does, ask first.
- Do not change router or network settings unless you own them and know why.
- Blur your username and other personal details before sharing screenshots.
- Save your work in **your own portfolio repository**, not in this course repository.
