Welcome! This page gets you ready. The account itself is created in [Class 1](course/class-1-safe-account-and-billing.md), together with the safety settings, so do not skip ahead and click around in a brand-new account.

## ✅ What you need

- A modern web browser (Chrome, Edge, Firefox or Safari)
- An email address that only you read (this becomes your AWS **root** login)
- A phone for the verification code and an authenticator app (Google Authenticator, Microsoft Authenticator or similar) for MFA
- A **debit or credit card** that works for online payments. AWS verifies it with a small temporary charge. If you can, use a card or virtual card with a low limit
- Basic skills from **Linux**, **Bash** and **Git and GitHub for Beginners**
- About 2 to 3 hours of focus per class

You do **not** need coding experience or a powerful laptop.

## 💰 The honest money talk

- Doing the whole course, with every lab torn down on the same day, should cost **a few dollars**, and often less than that. See the table in the [overview](course/00-overview.md).
- AWS has changed its free allowance over the years. **Do not assume it covers you.** In Class 1 you look at the Free Tier page in your own account and read what it says.
- Forgetting one load balancer or database for a month can cost **more than the rest of the course together**. That is why clean-up is a graded part of every class.

## 🖥️ Your practice terminal: CloudShell

You will not install anything on your own computer. AWS gives you a free Linux terminal in the browser called **CloudShell**. You open it in Class 1.

1. Sign in to the AWS console.
2. Click the small terminal icon (`>_`) in the top bar, or search for **CloudShell**.
3. Wait for the prompt. You are on a Linux computer that is already signed in as you.

CloudShell is a Linux terminal like the ones in your earlier courses, so every command works the same. Do **not** paste these commands into Windows PowerShell.

## 💼 Your portfolio

Use the `my-devops-portfolio` repository from the Git course. Your notes, screenshots and assignment go in an `aws/` folder there. Keep it **Private** until you have checked that it holds no account numbers, keys or passwords.

You will **not** put your work in this course repository.

## 🔒 Safety first

- Read a command before you run it, especially one that deletes.
- Cover or crop your **account number** and **email** in screenshots.
- Never type a password or key into a file that goes to Git.
