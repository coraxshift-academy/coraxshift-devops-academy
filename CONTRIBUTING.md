# Reporting a problem

This repository is public while the courses are being reviewed and tested. If something does not work on your machine, reporting it is genuinely useful.

## Before you report

Run the lab again on a clean machine or a fresh Codespace. Most mismatches come from something left over from an earlier lab.

## Report a broken lab

Open an issue and use the **Broken lab** template. Please include:

1. The course and class, for example `01-linux-for-beginners`, Class 2.
2. The exact step number and the exact command you ran.
3. What you expected to see, and what you actually saw.
4. Your environment: Codespace, WSL2, macOS, a cloud VM or a local Linux install.
5. The full error message, pasted as text rather than a screenshot when possible.

## Report a content error

Use the **Content error** template for a wrong explanation, a typo, a broken link or a cost figure that has changed.

## What we do not accept

- Pull requests that rewrite course content. The teaching voice is deliberate, so discuss the change in an issue first.
- Requests for course access. Enrolment is handled separately, not through issues.

## Security

Do not open a public issue for a security problem. Write to nahanonye@gmail.com.
