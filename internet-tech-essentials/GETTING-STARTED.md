# 🚀 Getting Started

**Internet & Tech Essentials** · Coraxshift DevOps Academy

</div>

This page gets you ready in about 20 minutes. You need three things: a computer you can open a terminal on, a free GitHub account, and a place to save your work (your portfolio).

## ✅ What you need

- A computer with a modern web browser (Chrome, Edge, Firefox or Safari)
- An internet connection
- A free GitHub account ([create one here](https://github.com/signup)) that has been **invited to this course repository**
- About 2 hours of focus per class

You do **not** need coding experience, a credit card, or a powerful laptop.

## 💼 Step 1: Create your portfolio (your own folder online)

Your portfolio is where you keep your work, so you can show it to future employers or clients. It lives in **your** GitHub account, not in this course repository.

1. Sign in to GitHub and click the **+** at the top right, then **New repository**.
2. Name it `my-devops-portfolio`.
3. Choose **Private** for now. You can make it public later, once you have checked it contains nothing personal.
4. Tick **Add a README file**, then click **Create repository**.

When a lesson says **Push to your portfolio**, you will upload your files here: open the repository, click **Add file → Upload files**, drag your files in, then click **Commit changes**. You do not need to learn Git yet.

## 🖥️ Step 2: Open a terminal

A **terminal** is a window where you type instructions and the computer answers. Class 1 shows you how to open it on Windows, Mac and Linux. You do not need to do anything now.

## 🧰 Step 3: VS Code (needed in Class 2)

VS Code is a free editor where you will write and read files. Choose **one** way:

- **Easiest, nothing to install:** use a free online editor. Go to [github.com/codespaces/new](https://github.com/codespaces/new), choose the **Blank** template, and click **Create codespace**. A VS Code editor opens in your browser. (Free accounts include monthly hours. Check yours under GitHub **Settings → Billing**.)
- **On your own computer:** download VS Code from [code.visualstudio.com](https://code.visualstudio.com/download) and install it like any other app.

## 🔒 Safety first

- Keep passwords, tokens and keys out of screenshots, AI tools and your portfolio.
- Blur your username and other personal details if you share a screenshot.
